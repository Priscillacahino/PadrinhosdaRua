# Requisitos consolidados

## Requisitos funcionais

- **RF01** - cadastrar e consultar pontos comunitários quando validados;
- **RF02** - identificar estruturas previstas/existentes no ponto;
- **RF03** - registrar situação de água e alimento;
- **RF04** - registrar necessidade de limpeza ou manutenção;
- **RF05** - associar responsável/voluntário de referência quando aplicável;
- **RF06** - registrar atendimento realizado;
- **RF07** - manter histórico das ações;
- **RF08** - controlar estoque de materiais e origem dos registros;
- **RF09** - acompanhar planejamento e construção das casinhas;
- **RF10** - exibir mapa quando a camada cartográfica for implementada;
- **RF11** - gerar indicadores do piloto;
- **RF12** - registrar ocorrência relacionada ao ponto;
- **RF13** - diferenciar dados reais, planejados e demonstrativos;
- **RF14** - impedir que uma simulação altere indicador real.

## Requisitos não funcionais

- **RNF01** - interface mobile first e responsiva;
- **RNF02** - funcionamento como PWA;
- **RNF03** - acessibilidade de teclado, foco e contraste;
- **RNF04** - minimização e proteção de dados pessoais;
- **RNF05** - persistência confiável quando banco for implantado;
- **RNF06** - rastreabilidade de operações relevantes;
- **RNF07** - desempenho adequado em celular intermediário;
- **RNF08** - documentação para continuidade por outra equipe;
- **RNF09** - comportamento offline definido;
- **RNF10** - critérios para exposição de localização;
- **RNF11** - nenhum segredo/chave em repositório;
- **RNF12** - dados demonstrativos visualmente identificáveis.
