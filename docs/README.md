# Documentação do Padrinhos de Rua

Esta pasta reúne a documentação acadêmica e técnica do projeto extensionista. O documento principal é o **Relatório Acadêmico Consolidado**; os demais arquivos detalham partes específicas sem substituir o relatório.

## Documento principal

- `Padrinhos_de_Rua_Relatorio_Academico_Consolidado.pdf` - versão para leitura e apresentação.
- `Padrinhos_de_Rua_Relatorio_Academico_Consolidado.docx` - versão editável.

## Apoio acadêmico e técnico

- `PROJETO_EXTENSIONISTA_COMPLETO.md` - consolidação ampliada do escopo.
- `CONTEXTO_E_DIFERENCIACAO.md` - contexto municipal e declaração de independência.
- `IMPACTO_PROS_CONTRAS.md` - benefícios potenciais, limitações e mitigação.
- `VIABILIDADE_FINANCEIRA.md` - estrutura de custos e critérios de transparência.
- `Planilha_Viabilidade_Financeira_Piloto.xlsx` - modelo para cotações e custos reais.
- `REQUISITOS.md` - requisitos funcionais e não funcionais.
- `REGRAS_DE_NEGOCIO.md` - regras para separar planejamento, demonstração e execução real.
- `MODELO_DE_DADOS.md` - proposta de entidades e classificação dos dados.
- `PRIVACIDADE_E_SEGURANCA.md` - minimização, localização e tratamento de dados.
- `OPERACAO_E_MANUTENCAO.md` - responsabilidades e continuidade operacional.
- `INDICADORES_E_VALIDACAO.md` - métricas e critérios de avaliação do piloto.
- `PLANO_DE_PROTOTIPACAO.md` - evolução das telas e leitura dos protótipos.
- `ROTEIRO_VIDEO_DEMONSTRACAO.md` - roteiro acadêmico para demonstração em vídeo.
- `LIMPEZA_E_REAPROVEITAMENTO_CODIGO.md` - decisões de simplificação do MVP.
- `HISTORICO_AJUSTES.md` - histórico das correções consolidadas.

## Estado de referência

Na versão consolidada de setembro de 2026, o projeto registra **0 casinhas instaladas** e uma meta piloto de **até 10**, condicionada a validação, materiais, segurança, responsáveis e autorização. Dados usados para demonstrar o MVP não compõem resultados reais.
