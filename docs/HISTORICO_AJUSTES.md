# Histórico de ajustes mobile - Padrinhos de Rua

Este documento registra a transição do protótipo operacional inicial para a fase piloto mobile.

## Alterações consolidadas
- Meta inicial limitada a **10 casinhas**.
- Fluxo **mobile first** com navegação: Início, Mapa, Oficina, Estoque e Perfil.
- Oficina simplificada para voluntários.
- Estoque com cálculo de disponibilidade, necessidade e déficit.
- Reserva de materiais ao iniciar uma montagem.
- Pontos de água e comida mantidos como parte central do projeto.
- Reporte de problema disponível a partir dos pontos.
- Planejamento limitado às casinhas #1 a #10.
- Protótipos mobile organizados em `prototipos/mobile`.

Os locais futuros devem ser tratados como previsões e dependem de validação e autorização.
