# Pacote de ajustes mobile — Padrinhos de Rua

Este pacote contém os arquivos revisados para a fase piloto do projeto.

## Alterações principais
- Meta inicial limitada a **10 casinhas**.
- Fluxo **mobile first** com navegação inferior: Início, Mapa, Oficina, Estoque e Perfil.
- Oficina simplificada para voluntários, sem aparência de linha industrial.
- Estoque com cálculo do que existe, do que falta e de quantas casinhas podem ser iniciadas.
- Reserva automática dos materiais ao iniciar uma montagem.
- Pontos de água e comida preservados como parte central do projeto.
- Reporte de problema disponível a partir dos pontos.
- Planejamento limitado às casinhas #1 a #10.

## Arquivos que substituem o repositório
- `src/App.tsx`
- `src/data/oficinaData.ts`

## Protótipos
A pasta `prototipos/mobile` reúne as telas produzidas para reprodução no Figma.

## Observação
Os locais das casinhas 7 a 10 foram deixados como **a definir** para evitar apresentar como decisão tomada um ponto que ainda depende de validação e autorização.
